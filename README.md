# Air Compressor Fault Detection System

A MATLAB-based application for detecting faults in air compressors using audio signal processing, feature extraction and machine learning.

## Application

![Air Compressor Fault Detection System](images/app-screenshot.png)

## Features

- Load compressor audio signals
- Visualise signal waveforms
- Audio playback
- Extract signal features
- Automatic fault classification
- Interactive MATLAB App Designer interface

## Extracted Features

- RMS
- SINAD
- Shape Factor
- Zero Crossing Rate (ZCR)
- Crest Factor
- Kurtosis
- Peak Frequency
- Band Power
- Spectral Centroid
- Spectral Spread
- Spectral Flux

## Technologies Used

- MATLAB
- MATLAB App Designer
- Signal Processing
- Feature Extraction
- Machine Learning
